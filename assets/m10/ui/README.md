# M10 UI / editable vector masters

These clean SVG masters are authored for the L.I.V.E. research-console design system. They are **not screenshots** and contain no baked-in character names or dynamic values. SVG shapes can be edited with Illustrator, Inkscape or other vector editors. In the M10-01 prototype, the PixiJS component system draws responsive geometry programmatically; these masters establish reusable source shapes for later sprite export and nine-slice refinement.
