# ER Auto Chess — Combat Sandbox v0.3

업로드용 완성본. 이 폴더의 내용물을 GitHub 저장소 루트에 그대로 업로드하면 된다.

- 32명 전체 roster / 기본 스탯 / 1~3★
- A/B 각 최대 3명 자유 편성 및 3×3 배치 → 3×6 전투
- 6명 기존 구현 스킬: 슈린, 마커스, 유민, 니키, 리오, 유스티나
- 나머지 26명은 기본 전투만 가능하며 스킬은 SKILL PENDING
- SD 슬롯: assets/characters/<id>.png (파일이 없으면 placeholder)
- 32명 roster browser + 검색/코스트/역할/소속/구현상태 필터
- source/target 피해 통계 유지

행 = same y / 열 = same x.
