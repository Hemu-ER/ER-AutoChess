# ER Auto Chess Combat Sandbox v0.2

6인 전투 구현을 캐릭터 상세 설정집 v1.1 및 통합 기획서 v0.2의 계수와 다시 대조한 감사(audit) 버전.

## 이번 수정
- 유민: 전투 시작 즉시 적 전체 피해, 1초 뒤 전체 0.5초 행동불능, 바람 최대 2중첩, 매초 지속 피해, 최대 중첩 대상 기본 공격 시 추가 피해 구현.
- 슈린: 결심응진(3회 기본 공격 후 다음 기본 공격), 피해 절반 회복, 결심응진 3회 후 만검귀종, 3초간 모든 기본 공격 결심응진 적용.
- 마커스: 10초마다 지각변동 전체 피해 + CC + 충격, 충격 대상 기본 공격 시 소비/추가 피해/0.5초 CC.
- 니키: HP 50% 이하 다혈질, 2★ 기준 ATK/AMP/AS +30%; 가드&카운터 20% 확률, 피해 80% 경감, AMP 100% 반격.
- 리오: 8초마다 0.5초 정신 집중 후 최근접 대상 정사필중 ATK 400%, 인접 적 절반 피해. 카에유미 적용.
- 유스티나: 2회 기본 공격 후 같은 '열'(좌/중/우 라인) 관통 포격, 다음 기본 공격 부스트 대쉬. 현재 QA 계수 95%/50% AMP.
- 3바니: 최신 QA안 35% 확률 × 적응형 50% 추가 피해.
- 3수영복: 공유 15회 기본 공격마다 적 전체 최대 HP 5% 고정 피해.
- 소속 시너지 단계는 전투 시작 시 잠금. 사망해도 단계가 내려가지 않음.
- 역할 시너지는 실제 전투 시작 시 최종 배치 위치 기준으로 다시 적용.
- 첫 기본 공격은 t=0 즉발이 아니라 1/AS 뒤 시작.
- CC 중 기본 공격/이동/스킬/채널링 금지. 리오 정신 집중은 CC로 중단.
- 60초 제한 시 남은 HP 비율 합계 비교.

## 아직 QA 임시값
- 이동: 공격 대상이 없을 때 전방 1칸이라는 규칙은 확정이나, 이동 간격은 미정. UI의 기본 0.5초는 임시값.
- 리오 카에유미 거리별 곡선: 최대 보너스는 확정 초안(+40% at 2★), 거리 1/2/3에 최대치의 100%/66.7%/33.3% 적용은 임시값.
- 마커스 지각변동 행동불능 지속시간: 문서에 정확한 시간이 없어 1.0초 임시값.

## 피해 출처 상세 통계

딜미터에서 캐릭터의 **상세** 버튼을 누르면 출처별 발동/적중/Raw/실제 피해가 표시된다. 전투 중에도 갱신되며 펼친 상태를 유지한다.

- `unit.damage`의 basic/skill/passive/synergy 합계는 기존대로 유지한다.
- `unit.damageSources[sourceName]`은 `{kind, activations, hits, raw, dealt}`를 보관한다.
- `activations`는 효과 실행 횟수다. 광역기는 대상별 피해 처리 전에 1회 기록한다. 버프/CC처럼 피해 없는 효과도 `activateSource()`만 호출할 수 있다.
- `hits`는 실제 HP 피해가 양수인 대상별 이벤트 수다. 한 광역기로 2명을 맞추면 발동 1회, 적중 2회다.
- `raw`는 계수 계산 직후의 피해 입력값으로, 니키 가드와 방어력 경감 전 값이다. `dealt`는 경감 후 남은 HP로 제한한 유효 피해다. 이미 죽은 대상에는 raw/hits/dealt를 추가하지 않는다.
- 수영복 공유 카운터 발동은 기존 총 피해 귀속과 동일하게 마지막 기본 공격을 한 캐릭터에게 기록한다.
- 슈린의 강화 중 결심응진도 같은 출처에 합산하지만 다음 만검귀종 준비 횟수에는 포함하지 않는다.
- 새 피해는 `damage(..., {sourceName: '출처명', ...})`로 계측한다. 새 발동은 `activateSource(unit, '출처명', kind)`로 기록한다. `sourceCatalog`는 아직 발동하지 않은 출처도 0으로 표시하기 위한 메타데이터다.

## 테스트

Node.js로 저장소 루트에서 실행:

```sh
node --check game.js
node tests/combat.cjs
node tests/shurin.cjs
node tests/damage-stats.cjs
```

`tests/fixtures/pre-stats.game.js`는 계측 전 커밋 `37ddc12`의 전투 엔진 스냅샷이다. 회귀 테스트는 이 기준과 101개 seed의 피해 이벤트, 매 틱 HP/상태, 난수 진행과 승패를 비교한다. 이 파일은 제품에서 로드하지 않는다.
