# ER AutoChess v0.3.2 — Synergy QA Complete

이 ZIP은 저장소 루트에 그대로 덮어쓰기 위한 완성본이다.

## 이번 버전 핵심 수정
- 소속 시너지의 실제 전투 효과와 표시 상태를 같은 엔진 상태에서 읽도록 통일.
- 전투 시작 로그에 A/B팀의 확정 소속 시너지 단계와 각 실험체 역할 시너지 ON/OFF 표시.
- 편성 패널에서 소속 시너지 `N단계 ON` / 인원 부족 `미발동` / 에레보스 `효과 미정` 표시.
- 군악대: 기존에는 타이머만 생기고 실제 ATK/AMP/AS가 오르지 않던 버그 수정.
- 마츠리: 기존에는 최대 HP만 오르고 ATK/AMP가 실제 피해 계산에 반영되지 않던 버그 수정.
- 메이드 3단계: 클리닝 20당 DEF +3, 100에서 +15 상한, 200에서 소비+회복으로 수정.
- 바니걸 3단계: 최신 체크포인트 기준 40% 확률 / 적응형 75% 추가 피해로 수정.
- 새해 3단계: 최신 체크포인트 기준 30회 피격 후 제거 유지.

## 현재 소속 시너지
- 파자마 2/3: 10초마다 수면, 피격 해제 + 공격자 AMP 100/200% 추가 피해
- 바니걸 2/3: 기본 공격 시 20%/40%, 적응형 50%/75% 추가 피해
- 수영복 2/3: 공유 기본 공격 20/15회마다 적 전체 최대 HP 3%/5% 고정 피해
- 마츠리 2/3: 처치 시 5/10초, 전 아군 ATK/AMP 및 최대 HP +15%/+30%
- 프리즌 2/3: 피해 적중마다 +1/+2, 20중첩 시 1/1.5초 행동불능; 프리즌 실험체 CC 50% 감소
- 군악대 1/2: 회복 받은 아군 5/10초 ATK/AMP/AS +10%/+20%
- 새해 1/2/3: 전 아군 HP +5/10/20%, DEF +10/20/30; 기본/스킬 10/20/30회 피격 후 제거
- 악마사냥꾼 2/3: 소속 실험체 공격 시 적응형 30%/60% 추가 피해
- 메이드 2/3: 클리닝 공유 스택, DEF 증가, 200에서 소비 후 전 아군 최대 HP 10%/15% 회복
- 애증 1: 케네스가 어느 팀에든 있으면 가넷 AMP/AS +30%, 최대 HP/DEF +20%
- 치유의 노래 1: `치유의 빛` 발동 훅은 구현됨. 샬럿 본체 스킬이 아직 미구현이므로 자동 발동은 아직 없음.
- 에레보스: 원 기획대로 현재 효과 미정/미적용.

## 역할 시너지
전사 / 탱커 / 암살자 / 원거리 평타 / 원거리 스킬 / 근거리 스킬 / 서포터 7종을 적용한다. 배치형 역할은 전투 시작 시 최초 3×3 배치를 기준으로 잠근다.

## 자가검토
아래를 실제 Node 실행으로 통과한 상태다.

```text
node --check combat-engine.js                  PASS
node --check game.js                           PASS
node tests/synergy-tests.cjs                   PASS
node tests/synergy-regression.cjs              PASS
```

`synergy-regression.cjs`는 32명 전투 진입, 엔진 시너지 단계 노출, 역할 7종, 서포터 중첩, 새해 제거, 군악대 실제 스탯 증가, 마츠리 실제 공격 증가, 프리즌/CC 감소, 파자마 10초 발동, 바니걸 피해, 수영복 공유 카운터, 악마사냥꾼 피해, 메이드 정확한 DEF/회복 주기, 애증, 치유의 노래 훅을 검사한다.

## 의도적으로 아직 없는 것
- 에레보스 효과: 기획 자체가 미정.
- 샬럿 `치유의 빛` 자동 발동: 샬럿 스킬 본체가 아직 미구현.
- 미구현 26명의 개별 액티브/패시브: 임의로 만들지 않고 기본 공격만 수행.
