# ER AutoChess v0.4 — 32명 스킬 QA 빌드

이 빌드는 `ER_오토체스_32명_캐릭터_상세설정_v1.1`의 32명 스킬 기능을 전투 엔진에 연결하고, 기존 역할/소속 시너지와 함께 QA할 수 있도록 만든 빌드다.

## 이번 버전 핵심

- 32/32 실험체 `SKILL READY` 처리 (`SKILL PENDING` 제거)
- 32명의 액티브/패시브 전투 핸들러 연결
- 스킬 실제 발동 시 전투 로그에 `[스킬] 캐릭터 → 스킬명` 출력
- 기존 역할/소속 시너지 유지
- 캐시 후열 우선 타겟팅, 클로에 니나 소환, 이안/제니 부활, 하트 불사, 요한 CC 면역 등 특수 판정 포함
- 버니스/로지 실제 2회 기본 공격 판정 유지
- 유스티나 같은 행 = same y, 버니스 같은 열 = same x 기준 사용

## 숫자에 대한 주의

상세설정집 v1.1은 기능 Source of Truth지만 일부 최종 수치가 미확정이다. 이미 대화에서 확정된 QA 계수는 그대로 사용했다. 문서에도 수치가 없고 별도 확정값도 없는 항목은 기능 QA를 위해 `QA` 상수에 임시값을 격리했다. 현재 대표 임시값은 라우라/아야/미르카 CC 시간, 버니스 공속 감소량/시간, 데비&마를렌 모드 소폭 보너스, 이렘 시작 공속 증가량, 샬럿 버프 지속시간이다. 기능 구조를 바꾸지 않고 나중에 숫자만 교체할 수 있다.

## QA 로그

스킬이 실제 발동하면 다음 형태로 로그에 남는다.

`[8.0] [스킬] 리오 → 정사필중`

단순히 스킬 데이터가 존재하는 것과 실제 발동을 구분하기 위해 activation 시점에만 기록한다.
